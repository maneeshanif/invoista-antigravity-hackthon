# AI Workflow Rules

## Antigravity Agent Instructions

Use this project context to:

1. Generate backend FastAPI structure
2. Generate MCP server tools
3. Generate agent orchestrator flow
4. Generate Supabase schema and seed data
5. Add trace logging everywhere

## Scope & Delivery Approach
- Focus on building a balanced hackathon MVP.
- Agent trace visibility is the main priority, followed by booking logic, then optional extras.
- Do not build complex real-world features like maps, payments, chat, or real provider integrations.
- Always implement against these constraints.
